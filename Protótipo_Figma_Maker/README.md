# Prototipo Figma Maker

Esta pasta guarda o prototipo exportado do Figma Maker. Ela nao e o frontend principal da aplicacao Spring Boot.

Use esta versao apenas como referencia visual ou para experimentar telas antes de levar mudancas para `acervo-museu/frontend`.

## Como rodar

```bash
pnpm install
pnpm dev
```

## Estrutura

```text
src/
  main.tsx
  app/
  styles/
```

Os arquivos de codigo do prototipo ficam dentro de `Protótipo_Figma_Maker/src/` para nao misturar com o frontend oficial do projeto.
